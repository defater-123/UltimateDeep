# 🧠 DeepSeek+

**DeepSeek+** — это сайт чата с нейросетью, который можно бесплатно разместить на **GitHub Pages**. Просто статические файлы: HTML + CSS + JavaScript, без сервера и без сборки.

🔗 Демо: `https://<ваш-логин>.github.io/deepseek-plus/`

## Возможности

- ✨ Красивый тёмный интерфейс в стиле современных AI-чатов
- 🤖 Два режима работы:
  - **Live-режим** — настоящие ответы нейросети через [DeepSeek API](https://platform.deepseek.com) (пользовательский ключ хранится только в браузере)
  - **Демо-режим** — локальная имитация ответов, сайт работает сразу без ключа
- 📝 Простой markdown в ответах (блоки кода, жирный текст)
- ⌨️ Enter — отправить, Shift+Enter — новая строка
- 💾 Контекст диалога для API-режима
- 📱 Адаптивная вёрстка (телефон / планшет / десктоп)

## Структура проекта

```
deepseek-plus/
├── index.html   # разметка: приветственный экран + интерфейс чата
├── style.css    # оформление (тёмная тема, анимации)
├── app.js       # логика чата: API-запросы, демо-движок, UI
└── README.md
```

## Установка и запуск на GitHub Pages

1. Создайте репозиторий, например `deepseek-plus`.
2. Загрузите файлы в корень репозитория (через `git push` или веб-интерфейс **Add file → Upload files**):
   ```bash
   git add .
   git commit -m "DeepSeek+: chat site"
   git push
   ```
3. Откройте **Settings → Pages**.
4. В разделе **Branch** выберите `main` / `/(root)` и нажмите **Save**.
5. Через 1–2 минуты сайт будет доступен по адресу:
   `https://<логин>.github.io/deepseek-plus/`

## Как включить настоящую нейросеть

1. Зарегистрируйтесь на [platform.deepseek.com](https://platform.deepseek.com) и создайте API-ключ (`sk-...`).
2. На стартовом экране сайта вставьте ключ (или позже — через меню ☰ → Настройки).
3. Выберите модель: `deepseek-chat` или `deepseek-reasoner`.
4. Индикатор в шапке станет зелёным — чат работает через настоящий DeepSeek API.

> 🔒 Ключ хранится только в `localStorage` вашего браузера и отправляется напрямую в DeepSeek. Сайт ничего не логирует и никуда не передаёт.

## Локальный запуск

Любым статическим сервером, например:

```bash
python3 -m http.server 8000
# затем откройте http://localhost:8000
```
